# 网站设计与职责约定

目标是能在电脑和手机浏览器使用的围棋对弈工作台。棋盘是视觉中心，大厅提供真实房间和明确的开始入口，界面不展示虚构用户、对局或战绩。

色彩：棋院蓝 `#20354b` 用于导航和主要操作，纸白 `#f6f8fb` 用于页面，石灰 `#dfe5ec` 用于分隔，竹木 `#ddb474` 用于棋盘，松绿 `#337c6b` 用于在线状态，朱红 `#b24d4d` 用于错误与认输。

字体：标题采用中文宋体衬线，界面文字采用系统中文无衬线。棋盘坐标和倒计时使用等宽数字。

布局：顶部品牌与主导航；大厅使用棋盘示意和开始面板；对局使用棋盘、棋手计时与聊天侧栏；手机布局改为纵向，操作始终可触及。

动效只回应操作：落子短暂缩放、提子即时更新、最近一手标记、按钮状态反馈；尊重减少动态效果设置。在线状态更新不抢走当前页面。

技术职责：React/TypeScript/CSS 只负责浏览器界面、用户输入与展示。账号、棋规、房间、匹配、计时、聊天、棋谱解析与回放、KataGo、SQLite、HTTP/WebSocket 和静态文件服务全部由 C++ 实现。Node.js 只用于前端构建，不是生产后端。

设计复核：保留与围棋相关的木质棋盘，以蓝灰工作台承托；不采用营销落地页、重复卡片阵列、虚构统计或持续背景动画。
